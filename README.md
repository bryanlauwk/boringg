# Clicker Toy

The Global "I'm Bored" Button
A real-time, anonymous activity tracker.

The Idea: A giant button in the center of the screen that says "I'm Bored."

The Interaction: Every time someone clicks it, a pixel on a massive global canvas changes color or a "boredom meter" rises. You can see how many people are clicking it right now and a heatmap of which countries are currently the most bored.
